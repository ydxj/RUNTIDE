# Code of Conduct

We follow the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

* Be respectful and constructive; assume good faith.
* No harassment, discrimination, personal attacks or publishing others' private information.
* Critique code and ideas, not people.
* Maintainers may remove comments, commits or contributors that violate these rules.

Report problems privately to the maintainers using the contact in [SECURITY.md](SECURITY.md) (replace with the
project's published address once the repository exists).
